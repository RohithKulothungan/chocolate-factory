# The Chocolate Factory

A modern marketing website for an artisan Belgian chocolate brand — built with React, Vite, and Tailwind CSS.

## Features

- Responsive single-page marketing site
- Hero, product showcase, brand story, craft process, testimonials, and newsletter signup
- Premium chocolate-inspired design with custom color palette and typography
- Smooth animations and hover interactions

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
npm run preview
```

## Tech Stack

- [React 19](https://react.dev/)
- [Vite 8](https://vite.dev/)
- [Tailwind CSS 4](https://tailwindcss.com/)
